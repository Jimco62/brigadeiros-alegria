# Receta Estándar - Clásico Alegría (con maracuyá)

**Objetivo:** Que siempre salga igual. Pesar TODO.

| Ingrediente                    | Gramos        | Proveedor            | Costo Bs |
| ------------------------------ | ------------- | -------------------- | -------- |
| Chocolate 100% San Carlos      |               | San Carlos / Mercado |          |
| Leche condensada               | 395g (1 lata) | Pil                  |          |
| Mantequilla sin sal            |               |                      |          |
| Pulpa de maracuyá para relleno |               | Abasto               |          |
| Azúcar para reducir maracuyá   |               |                      |          |

**Procedimiento:**
1. Reducir pulpa de maracuyá con azúcar hasta mermelada espesa. Enfriar y hacer bolitas congeladas.
2. Derretir chocolate + leche condensada + mantequilla a fuego bajo hasta punto brigadeiro (despega de olla).
3. Enfriar 4h. Pesar bolitas de 20g, insertar bolita de maracuyá congelada de 5g, cerrar y bolear.
4. Rebozar (granillo de chocolate San Carlos rallado).

**Rendimiento:** __ brigadeiros de 25g
**Tiempo de conservación:** 3 días refrigerado.
